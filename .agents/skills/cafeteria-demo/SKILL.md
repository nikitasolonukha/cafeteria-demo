# Кафетерий льгот — демо (полный скоуп)

Полное ТЗ лежит в `docs/TZ-full.txt`. Боевой контур (1С, SSO, Kubernetes, реальная почта, Giftery/ПВК, 2FA) в демо не входит: всё симулируется в UI и `localStorage`. Код наружу не готовить, пока не попросят.

Визуал зафиксирован в `DESIGN.md`. Направление заново не выбирать. После крупных экранов — аудит `design-anti-slop` по коду. Доступность — один проход `web-design-guidelines` в конце. Деплой — только по просьбе, скил `deploy-to-vercel`.

## Стек

Next.js (App Router) + TypeScript + Tailwind. Имя пакета `cafeteria-demo`. Данные в `localStorage` ключ `cafeteria-demo-v4`, одна компания на браузер. Кнопка «Сбросить демо» возвращает сид. Сервера и настоящей авторизации нет.

## Правила, которые обязаны работать

Окно выбора: 1–31 октября 2026. Админ закрывает/открывает. При закрытом — каталог виден, оформление нет.

Баланс Марии: 5 000 сгораемых + 2 000 несгораемых. Списание сначала сгораемых. Грейды: A 8 000, B 5 000, C 3 500.

Пакет по грейду, перерасход блокирует подтверждение. Сертификат — код сразу, отмена недоступна. Доп. отпуск — согласование руководителем, отказ возвращает баллы. ДМС семья >65 — отказ. Декрет/ВИП — ограничения разделов.

**Переводы:** комиссия из настроек (по умолчанию 25%), мин. сумма. Списание у отправителя = сумма + комиссия; получатель получает сумму.

**Благотворительность:** выбор фонда и суммы; матчинг компании × множитель; сертификат участника в заказах/истории.

**Командные сборы:** пул с целью, взносы, прогресс.

**Лотерея:** билет за баллы, розыгрыш админом, публикация победителей.

**Опросы:** конструктор в пульте, прохождение на витрине, выгрузка результатов (копирование CSV).

**Новости:** CMS в пульте, комментарии на витрине, модерация.

**Аномалии:** правила по порогам; журнал; отметка «легитимно» / заморозка.

**Импорт сотрудников:** симуляция Excel (парсинг CSV/текста в пульте).

**Выгрузка в бухгалтерию:** формирование TSV/CSV из заказов за период.

## Экраны витрины

Логин, главная (талон, окно, новости, баннеры), пакет, опросник, каталог (полки/вложения), карточка, корзина, заказы, баллы (сгорание), здоровье (клиники/покрытие/замена), поддержка (вложения), переводы, благотворительность, командные сборы, лотерея, опросы, промо, достижения, соцпроекты, уведомления, предложение льготы.

## Экраны пульта

Дашборд (дыры 1С), согласования, сотрудники (+карточка, Exclusion, импорт), каталог (+коды), полки/категории, окно выбора, событийные начисления + burn-notices, обращения, аудит, аномалии, новости/баннеры, опросы, лотерея, фонды/матчинг, выгрузки (бухгалтерия + к выплате), роли/Exclusion, интеграции (статус-мок), сегменты, бюджеты, промо, настройки платформы.

## Не делать (реальные интеграции)

1С:ЗУП, SSO, SMTP, Giftery API, Kubernetes, настоящая 2FA. Всё это — экраны-заглушки или локальная симуляция.
