# Кафетерий льгот — демо

Кликабельное демо ГК «Альтаир»: витрина баллов сотрудника и пульт HR. Данные в `localStorage` (`cafeteria-demo-v4`), без сервера и авторизации.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Сценарий

1. Войти как **Мария** → собрать пакет → сертификат с кодом.
2. Оформить доп. день отпуска.
3. Войти как **Дмитрий** → согласовать.
4. Войти как **Анна** / **Павел** → дашборд, начисления, окно выбора, настройки.

На логине есть кнопка «Сбросить демо».
