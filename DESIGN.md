# Кафетерий льгот — визуальная система

Направление уже выбрано. Заново его не придумывать.

Продукт — расчётный талон сотрудника промышленной группы, не wellness-лендинг и не SaaS-кабинет. Человек открывает экран и сразу видит, сколько баллов осталось и что на них берётся.

Смелое место одно: крупный остаток баллов на главной, набор Unbounded, под ним отрывная линия талона. Остальной интерфейс тихий.

## Токены

| Имя | Hex | Роль |
|---|---|---|
| `--paper` | `#E4E9E4` | Фон страницы. Холодный серо-зелёный, стена столовой |
| `--surface` | `#F7F8F6` | Плоскость панели |
| `--ink` | `#1A2421` | Текст |
| `--muted` | `#5C6B64` | Вторичный текст |
| `--line` | `#C5CFC8` | Границы, отрывная линия |
| `--stamp` | `#9E2B2B` | Единственный акцент: остаток баллов и одна главная кнопка |
| `--stamp-ink` | `#F7F8F6` | Текст на кнопке `--stamp` |
| `--pine` | `#1D4E43` | Только раздел «Здоровье», не глобальный акцент |
| `--danger` | `#8C2F2F` | Списание, отказ, перерасход |
| `--ok` | `#1D4E43` | Исполненный заказ. Тот же pine, отдельный зелёный не заводить |

Чистый `#000` / `#fff` не использовать. Тени не использовать: глубина бордером `--line`. Радиус контролов `8px`. Блок талона с балансом — без скругления.

Высота соседних контролов в одном ряду: `40px`.

## Контролы и меню

Все селекты, поля и списки выбора — один язык:
- Триггер: `--surface`, бордер `--line`, радиус `8px`, высота `40px`, шеврон справа.
- Выпадающая панель: бордер `--ink` (плотнее триггера), фон `--surface`, без тени.
- Строка списка: `Имя · роль` или основной текст + вторичный. Hover — `--paper`.
- Активная/выбранная строка: заливка `--ink`, текст `--surface`. Не системный синий Windows и не indigo.

Компонент: `MenuSelect` / `MenuList`. Нативный `<select>` оставлять только во внутренних формах пульта, где кастомный список не нужен — стилизовать классом `control-field`.

## Шрифты

- **Onest** — интерфейс, текст, кнопки. Кириллица.
- **Unbounded** — только остаток баллов и цена в баллах. Больше нигде.

Inter, Geist, Roboto, системный стек, второй serif — нет.

## Каркас

Сотрудник, десктоп: левая рельса 232px, контент слева, не колонка по центру. Телефон: нижняя навигация из пяти пунктов, контент на всю ширину, отступ снизу под рельсу.

Пульт: левый сайдбар и таблицы на всю ширину рабочей области. Верхние табы как единственная навигация — нет.

Выравнивание слева. Карточка только у сущности каталога (льгота). Главная — не сетка одинаковых KPI.

## Запреты

Индиго и фиолетовый. Эмодзи в хроме. Цветной `border-left` у карточек. Пастельные пилюли `bg-green-100`. Капс на каждой подписи. `animate-ping` / `animate-pulse` на статусах. Тень при наведении. `transition-all`. Стрелка в конце каждой кнопки. Кремовый фон с терракотой и декоративный serif — это текущий шаблонный вид, не наш.

Статус заказа — короткое слово цветом `--ink` / `--muted` / `--pine` / `--danger` на `--surface`, без таблетки.

Акцент `--stamp` на экране: остаток и одна главная кнопка. Иконки не красить акцентом.
